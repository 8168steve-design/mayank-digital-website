# Mayank Digital — Photo-Match Theme

This Vite + React package displays the supplied photorealistic mountain-and-river design reference as a responsive full-page image so its landscape, typography, and glass cards match the reference as closely as possible.

## GitHub Pages
- `vite.config.js` is configured for `/mayank-digital-website/`.
- Keep your repository's existing `.github/workflows` deployment workflow when uploading these files.
- The composition is a single image, so its pictured buttons/navigation are visual only, not individual interactive controls. For a fully interactive recreation, the page would need to be rebuilt with HTML/CSS components and a separate real landscape background.

## Local preview
Run `npm install`, then `npm run dev`.
